Loading live status…

These come from GET /api/v1/node-pool/status on a node pool node, polled every 30 seconds. If it does not answer, every tile reads unavailable; a tile the node does not report reads —. Nothing is estimated or filled in.

Every node computes the same ledger from the same share chain, so any honest node should give the same balances. A node that is still syncing, or cut off from its peers, can lag.

The blocks found count is the node pool's. It has never found a block.
