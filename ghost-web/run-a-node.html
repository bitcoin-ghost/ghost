run a node

Run your own node.

The software behind Ghost Pool is open source, and one installer sets up a whole node on an Ubuntu machine: a Bitcoin full node, the pool, its SV1 ports 3333 and 4444 and SV2 port 34255, and a dashboard. Point your own miners at it and you mine solo on your own node.

what you get

Same rules, your own machine.

  • The payout rule is compiled into the pool: a block found on your node pays its miner the subsidy and every fee, less 0.5% of the subsidy to the treasury, exactly as on the public nodes.
  • Your node builds its own block templates from its own mempool.
  • You can pair it with a second node of your own, so each submits the other's blocks (--peer-node).
  • A node of your own is not one of the two public Ghost Pool nodes, and it is not listed on this site.

install

One command.

Ubuntu 22.04 or newer, 4 GB of RAM, and at least 25 GB of disk for a pruned mainnet node (800 GB for a full archive). The first sync of the Bitcoin chain takes from several hours to a few days.

curl -fsSLO https://raw.githubusercontent.com/bitcoin-ghost/ghost/ghost-solo/scripts/install-node.sh
less install-node.sh            # read what it does first
sudo GHOST_VERSION=np-latest bash install-node.sh

Run it with no flags on a terminal for a guided setup, or bash install-node.sh --help for every option. Every binary it downloads is checked against the project's GPG release signature before it is installed. The installer is scripts/install-node.sh in the source repository.

Two nodes backing each other up

# on node A
sudo GHOST_VERSION=np-latest bash install-node.sh --peer-node <node B's IP> --submit-auth <B's rpcuser:rpcpassword>
# on node B
sudo GHOST_VERSION=np-latest bash install-node.sh --peer-node <node A's IP> --submit-auth <A's rpcuser:rpcpassword>

Each node sends every block its miners find to the other as well. Keep the link between them private (a VPN or a private network): the RPC password crosses it.
