Connect your miner.

username

Your Bitcoin address is your account.

  • Use bc1q… (SegWit), bc1p… (Taproot) or 3… (P2SH) addresses. Legacy 1… addresses are refused.
  • To tell machines apart, add a worker name after a dot: bc1q…xyz.garage. Workers on the same address are added up on your miner page.
  • The password is ignored. Put x.
  • Use an address from a wallet you control, and check it twice: a block pays exactly the address in your username, and nobody can redirect or refund it.

step by step

By miner.

Bitaxe, NerdAxe and other AxeOS miners

  1. Open the miner's web page (its IP address in a browser) and go to Settings.
  2. Stratum URL: the first node's host name, without stratum+tcp://. Port: 3333.
  3. Stratum user: your address, optionally .worker. Password: x.
  4. Newer AxeOS versions have a Fallback pool: set the second node there, also port 3333.
  5. Save and restart. The miner shows up on your miner page within a minute of its first accepted share.

Avalon (Nano, Mini, Q and A-series)

  1. Open the miner's web page or the Avalon app, and go to the pool settings.
  2. Pool 1: stratum+tcp://<first node>:3333 for Nano and Mini, :4444 for A-series machines.
  3. Worker: your address, optionally .worker. Password: x.
  4. Pool 2: the second node, same port and worker.

Antminer (stock firmware)

  1. Open the miner's web page and go to Miner Configuration (or Settings → Pools).
  2. Pool 1 URL: stratum+tcp://<first node>:4444. Worker: your address, optionally .worker. Password: x.
  3. Pool 2 URL: stratum+tcp://<second node>:4444, same worker and password.
  4. Save and apply. The miner switches to pool 2 by itself if pool 1 stops answering.

Braiins OS

  1. Go to Configuration → Pools and add a pool group.
  2. Add both nodes as stratum+tcp://<node>:4444 with your address as the user and x as the password. The order sets which is tried first.
  3. To use Stratum V2 instead, add each node's SV2 URL from the list above, including the authority key: stratum2+tcp://<node>:34255/<authority key>.

Stratum V2 (any SV2 miner or proxy)

  1. Connect to port 34255 of either node. SV2 connections are encrypted and the miner checks the node's identity against its authority key: use the key published for that node above, and never a key you got anywhere else.
  2. The user identity is your address, optionally .worker, exactly as for SV1.
  3. Both standard and extended channels are supported. Job Declaration, where your own node builds the block template, is coming soon.

check

Is it working?

Look up your address on the miner lookup page: you should see your workers online and shares being accepted. A few stale shares are normal. If nothing appears after a few minutes, check the address in the username, and that the miner reaches the node's port (some networks block outgoing ports other than 80 and 443).
