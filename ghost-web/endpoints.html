This list is generated, not curated: any node with a valid advert that passes an outside probe is listed, and nothing else decides it. No roster, no approval, no signed list. The generator is ghost-audit list: it finds nodes from the relays' own address gossip, reads each node's advertised stratum ports from its relay port, and probes them like a miner would. A node is listed after 3 passing probes out of its last 6, with no failed probe among them, and taken off after 3 probes in a row that did not pass, or at once after a failed one. A probe that could not measure a node never counts as a pass. How listing works →

Region is not shown: nothing the probe measures says where a node is.

Being listed means a node answered a probe. It does not mean the node is honest. A miner on someone else's node who does not audit it with ghost-audit is trusting it. Auditing a node →
