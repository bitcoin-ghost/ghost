Mining endpoints

Point at any node. Mine the whole pool.

Every public Ghost node is a valid entry point. Connect an ASIC to any one of them and the mesh load-balances your hashrate across the pool automatically — the balancing happens at the nodes, not at a central proxy. So this list is a bootstrap seed: pick a couple, set them as your pool + fallbacks, and no single address can ever strand you.

how it routes

The balancing is at the nodes.

You don't need a smart address to reach a lightly-loaded node — you just need to reach any node. When your miner connects, that node checks the live mesh and, if a less-loaded peer exists, transparently forwards your Stratum session to it. Your miner never notices. That's why any entry point works, and why losing one address doesn't cost you the pool.

resilient setup

Set a primary and fallbacks.

Mining firmware fails over automatically when a pool drops. Give it more than one Ghost node — a primary plus one or two fallbacks from the list above — and your rig keeps hashing even if a whole node (or an address) goes offline. Use the fixed stratum ports: :3333 for V1, :34255 for V2.

  • Bitaxe / AxeOS
    In the web UI under Settings, set pool.bitcoinghost.org:3333 (or any node from the list) as the Stratum host, and a second node as the Fallback Stratum host. AxeOS switches to the fallback automatically if the primary stops responding.
  • CGMiner / BFGMiner
    Pass each node as its own --url; they're tried in priority order with automatic failover:
    --url stratum+tcp://pool.bitcoinghost.org:3333 --url stratum+tcp://<node-2>:3333 --url stratum+tcp://<node-3>:3333
    Use the same --user <your-bc1…-address> on each.
  • Your address is your username
    Ghost has no accounts. Your bc1… payout address is your Stratum username — set it the same on every node so all your shares aggregate to one payout, whichever node you land on.
Coming: a verifiable, consensus-signed node list a small local helper can follow automatically — so discovery needs neither DNS nor this page after first run. For now, a primary plus a fallback or two gives you address-independent resilience today.
